# Modern House OMS — نظام إدارة العمليات والمبيعات المتكامل

نظام إدارة عمليات ومبيعات شامل ومفتوح المصدر (Open Source OMS) مخصص للشركات التجارية، معارض المطابخ، الأجهزة المنزلية، والمقاولات.  
يعمل النظام محلياً وسحابياً عبر واجهة سطح مكتب (Desktop Electron)، متصفح ويب، وتطبيقات الأجهزة اللوحية والهواتف الذكية (Tablet/Mobile PWA).

---

## 🌟 أبرز المميزات (Key Features)

1. **دورة المبيعات المتكاملة (Workflow from Quote to Cash):**
   - إدارة كاملة لدورة العمل: استفسار ← عرض سعر ← أمر بيع ← تجهيز وتوصيل ← صيانة وتحصيل.
   - تحويل عروض الأسعار بضغطة زر إلى فواتير معتمدة.
2. **نظام الكاشير السريع (POS):**
   - فواتير فورية مع دعم الباركود وحساب ضريبة القيمة المضافة (VAT).
3. **الفاتورة الرقمية الموثقة ورمز الـ QR:**
   - توليد رمز QR ديناميكي على الفاتورة يفتح صفحة التحقق الإلكترونية المعتمدة للعميل أو المفتش عبر الرابط المحلي أو السحابي.
4. **ملف العميل الموحد (Customer 360):**
   - شاشة واحدة تجمع كافة فواتير العميل، عروض أسعاره، مدفوعاته، عقود المطابخ، وأوامر الصيانة.
5. **إدارة المخزون والتنبيهات الذكية:**
   - تنبيهات انخفاض المخزون حسب الحدود المخصصة لكل صنف لمنع انقطاع البضاعة.
6. **دقة الحسابات والأرباح:**
   - ربط دقيق لتكلفة البضاعة المباعة (COGS) ووسم الأرباح غير المكتملة تلقائياً في حال غياب تكلفة الشراء.
7. **الأمان والصلاحيات:**
   - تسجيل دخول سريع برمز PIN لكل موظف مع أدوار محددة (مدير، كاشير، بائع، فني توصيل).
   - حماية قاعدة البيانات محلياً مع نسخ احتياطي دوري تلقائي في `D:\oms\backups`.

---

## 🛠️ البنية التقنية (Tech Stack)

* **الواجهة الأمامية (Frontend):** React 19, TypeScript, Vite, Tailwind CSS, Lucide Icons, Framer Motion.
* **تطبيق سطح المكتب (Desktop App):** Electron, Node.js (CommonJS bridge).
* **قاعدة البيانات (Database):** SQLite محلية فائقة السرعة والأمان (`D:\oms\oms.sqlite`).
* **الربط السحابي والشبكي (Networking):** Node.js HTTP Server + Cloudflare Tunnels للوصول السحابي الآمن.
* **الطباعة والمستندات (Document Engine):** jsPDF, html2canvas, QRCode generator.

## 🚀 التشغيل والتطوير (Getting Started)

### المتطلبات المسبقة:
* تثبيت **Node.js** (الإصدار 18 أو أحدث).
* توفر **npm** أو **pnpm**.

### 1. تثبيت الحزم:
```bash
npm install
```

### 2. تشغيل واجهة الويب في وضع التطوير:
```bash
npm run dev
```

### 3. تشغيل تطبيق سطح المكتب (Electron):
```bash
npm run desktop:start
```

### 4. تشغيل الاختبارات الآلية (Automated Tests):
```bash
npm run desktop:test
```
*(يحتوي المشروع على 58 اختبار تكامل ووحدات برمجية تغطي الأمان، المصادقة، والعمليات الحسابية).*

### 5. بناء الحزمة الإنتاجية النهائية:
```bash
npm run desktop:build
```


# Modern House OMS 1.1.0 — نسخة ويندوز المحلية

## تحسينات الإصدار

- حفظ البيع والمخزون والتوصيل والتنبيهات المرتبطة في معاملة واحدة، مع التراجع الكامل عند فشل أي خطوة.
- تعديل الطلب وحذفه يعتمدان على البيانات المحفوظة والمخزون الحالي، مع تجميع الأصناف المتكررة.
- استلام طلب الشراء يزيد المخزون مرة واحدة فقط، مع حفظ الحالة والمخزون معًا.
- ربط تحويل عرض السعر والطلب الوارد بالطلب الناتج داخل المعاملة نفسها.
- تعديل السجل مباشرة عبر الفهرس بدل تحميل المجموعة كاملة.
- طباعة إيصال نقطة البيع برقم الطلب المحفوظ فعليًا؛ يُفرَّغ السلة بعد الحفظ حتى لو تعذر تجهيز الإيصال.
- نسخ احتياطي دوري أثناء العمل وعند الإغلاق المعتاد، واسم المنتج وإصداره وأيقونته داخل EXE.

## التشغيل

- `release/Modern-House-OMS-Setup-1.1.0.exe`: برنامج التثبيت النهائي لويندوز 64 بت.
- `release/Modern-House-OMS-Portable-1.1.0.exe`: تشغيل مباشر دون تثبيت. لا يحتاج Node.js على جهاز المستخدم.
- يعمل على Windows 10/11 بنظام 64 بت.
- هذه نسخة لجهاز واحد، وتفتح تلقائيًا بحساب مدير الجهاز. الوصول إلى حساب ويندوز يعني الوصول إلى بيانات البرنامج؛ ليست نظام دخول متعدد المستخدمين للحماية من مستخدمي الجهاز نفسه.

## البيانات والنسخ الاحتياطية

تُحفظ قاعدة SQLite هنا، خارج مجلد البرنامج:

`%APPDATA%\ModernHouseOMS\oms.sqlite`

تستخدم نسخة التثبيت ونسخة التشغيل المباشر الموقع نفسه على حساب ويندوز نفسه. نقل EXE وحده إلى جهاز آخر لا ينقل البيانات. تحديث البرنامج أو إزالة تثبيته لا يحذف مجلد البيانات.

من قائمة **البيانات المحلية** أو شاشة **الإعدادات**:

1. **حفظ نسخة احتياطية**: يحفظ جميع المجموعات، ومنها الصيانة وعروض الأسعار، والصور المرفوعة والإعدادات في ملف `oms-backup.json`.
2. **استعادة نسخة احتياطية**: يطلب ملفًا ثم يعرض تأكيد الاستبدال. تُنشأ نسخة من الوضع الحالي قبل الاستعادة. تُرفض النسخ غير الصالحة دون مسح البيانات.
3. **فتح مجلد البيانات**: يعرض مكان القاعدة والنسخ التلقائية.

تُحفظ نسخة عند بدء التشغيل، وكل 15 دقيقة بعد التعديلات، وعند الإغلاق المعتاد داخل `backups`، مع الاحتفاظ بآخر 48 نسخة حديثة و14 نسخة يومية حسب تاريخ الجهاز. النسخ السابقة للاستعادة تُحتفظ بها أيضًا. فشل النسخ التلقائي يُظهر رسالة ويُعاد المحاولة أثناء العمل. انسخ النسخ الاحتياطية إلى قرص خارجي لحمايتها من تعطل الجهاز. النسخ غير مشفرة، لذا احفظها في مكان موثوق.

## التثبيت على جهاز آخر ونقل البيانات

انقل ملف `Modern-House-OMS-Setup-1.1.0.exe` إلى جهاز ويندوز 64 بت، وشغّله وأكمل التثبيت، ثم افتح البرنامج من سطح المكتب أو قائمة ابدأ. ملف التثبيت يحتوي برنامجًا بقاعدة فارغة، ولا يحتوي بيانات جهازك الحالي.

لنقل البيانات: اختر **حفظ نسخة احتياطية** على الجهاز الحالي، وانقل الملف الناتج إلى الجهاز الآخر، ثم اختر **استعادة نسخة احتياطية** في البرنامج الجديد. نسخ الإصدار 1.0 المحلية متوافقة مع 1.1. لا توجد مزامنة تلقائية بين الأجهزة.

لتحديث جهاز عليه النسخة السابقة: احفظ نسخة احتياطية وأغلق البرنامج، ثم شغّل المُثبّت الجديد. بقي معرّف التطبيق ومجلد البيانات وصيغة النسخ الاحتياطية متوافقة. لم يُستبدل البرنامج المثبّت على جهاز التطوير خلال تجهيز هذه الحزمة.

## العمل دون إنترنت

السجلات، استيراد وتصدير Excel، التصميم والخطوط مضمّنة داخل البرنامج. الصور المرفوعة تُحفظ مع السجلات. الصور التي كانت روابط إنترنت تعرض صورة بديلة؛ ارفع الصور من الجهاز لتظهر دائمًا. روابط واتساب والخرائط تفتح في المتصفح الخارجي وتحتاج الإنترنت.

تبدأ النسخة بقاعدة فارغة وحساب مدير محلي. **بيانات Firebase الحالية لا تُنقل تلقائيًا**. استيراد العملاء والمنتجات متاح عبر Excel من الشاشات الأصلية. النسخ الاحتياطية المحلية لها صيغة مستقلة؛ تصدير Firebase يحتاج تحويلًا قبل استعادته هنا.

## إعادة البناء للمطور

من مجلد المشروع الرئيسي، بعد تثبيت التبعيات:

```powershell
npm install
node node_modules/electron/install.js
npm run desktop:test
node node_modules/typescript/bin/tsc --noEmit
npm --prefix src/desktop run dist
./src/desktop/verify-packaged.ps1
```

تتطلب مرحلة البناء اتصال الإنترنت لتنزيل التبعيات وأدوات التغليف. ملف EXE الناتج مستقل ولا يحتاج هذا الاتصال للتشغيل.

أمر البناء الافتراضي يكتب إلى `release`. أغلق أي نسخة تعمل من مجلد البناء قبل إعادة البناء فيه. وضع الاختبار يتطلب `--smoke-test` و`OMS_TEST_DATA_DIR` منفصلًا، ويستخدم فترة نسخ قصيرة للاختبار فقط؛ فترة الاستخدام العادي 15 دقيقة.

تُستخدم مداخل بناء مستقلة في `src/desktop`، مع استبدال Firebase بخدمة SQLite أثناء بناء نسخة الويندوز فقط. لم تُضف مزامنة سحابية إلى النسخة المحلية. منع الاتصال الخارجي وتقييد واجهة IPC مفعّلان، وواجهة العرض لا تملك صلاحيات Node.js.

مرجع التغليف: [Electron Builder NSIS](https://www.electron.build/v26/docs/nsis/). مرجع العزل: [Electron Context Isolation](https://www.electronjs.org/docs/latest/tutorial/context-isolation). مكتبة Excel مضمّنة من [توزيع SheetJS الرسمي](https://docs.sheetjs.com/docs/getting-started/installation/nodejs/).

ملفات EXE غير موقعة بشهادة ناشر تجارية. الاختبارات تغطي التخزين والمعاملات والنسخ والوظائف المعدلة، ولا تمثل اختبارًا لكل مسارات النظام أو لطابعة فعلية. القوائم الحالية ما زالت تُحمّل مجموعاتها كاملة؛ تقسيم صفحات كل الشاشات تحسين لاحق.
